# Presentation

`slides.md` is a 9-slide, 5-7 minute deck in Markdown (slides separated by `---`, presenter notes as `> Notes:` blockquotes).
Present with Marp: `npx @marp-team/marp-cli docs/presentation/slides.md` (add `--pdf` or `--pptx` to export, `-s` to serve), or open it in any Markdown viewer.
Marp renders the notes as part of the slide; delete the `> Notes:` blocks from an export if you do not want them shown.
Before presenting: fill in or delete the "Experiment 2 ... results pending" row on slide 7 using `docs/STATUS.md`.
